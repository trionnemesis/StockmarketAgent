METHODOLOGY

先證明資料，再討論方向。

Renderer 只讀取已驗證 JSON；它不在 HTML 或瀏覽器內重算研究分數。

PIPELINE

可重現的七道關卡

  1. 01
    Source policy

    官方、授權或明確允許的來源優先。

  2. 02
    Normalization

    日期、幣別、單位與公司行動分層處理。

  3. 03
    Point-in-time features

    只使用當時已公開的資料，避免前視偏誤。

  4. 04
    Deterministic model

    權重與門檻版本化；LLM 不決定數值或態度。

  5. 05
    Risk Gate

    缺資料、過期、矛盾或未校準時強制 NO_SIGNAL。

  6. 06
    Strict JSON

    拒絕未定義欄位、NaN、Infinity 與不合法日期。

  7. 07
    Derived outputs

    同一份 JSON 產生 Markdown 與靜態 HTML。

STANCE

四種研究態度

BUY
經校準後的買入傾向。
HOLD
方向不足或風險報酬中性。
SELL
經校準後的減碼傾向。
NO_SIGNAL
資料或模型條件不允許方向性結論。
